# Agora design decisions

Design direction: cinematic web3 builder landing page with a controlled-portal motif. ENERGY 2 / RHYTHM 2 / MOTION 2.

| Decision | Reason |
| --- | --- |
| Near-black, warm neutral palette with a muted moss accent | Financial status needs high contrast and calm focus. The moss accent marks bounded authority without a neon or speculative-trading look. |
| CSS portal in the landing hero | The light boundary gives one visual focal point for the product idea: access exists, but only through a defined opening. It is decorative and never carries product information. |
| Serif display type with a compact sans UI | The display face gives the public story gravity while Manrope keeps limits, labels, and operational information readable. |
| Solid dashboard surfaces with thin rules | Data views need stable edges and clear grouping. They do not use the hero treatment or glass effects. |
| Asymmetric landing sequence | The story moves from authority to process to the enforcement boundary to the architecture, rather than using a repeated feature-card grid. |
| Small, one-time visual transitions only | Motion supports the cinematic landing hierarchy. Reduced-motion users receive the same content without movement. |
| Pointer-responsive portal depth | Pointer movement shifts only the portal scene, reinforcing the controlled-access motif without moving financial content. |
| Animated fixture replay | A short status strip explains policy, quote, receipt, and delivery order while keeping the whole interaction labelled as a local fixture. |

## Content rules

- Public app values are labelled as synthetic fixtures.
- The page makes no performance, security, customer, or partnership claim.
- Payment confirmation and service delivery remain distinct states.
